# Pixel Loom

无需后端的场景化像素动画工作台。打开 `index.html` 即可使用。

## 功能

- **多场景**：每个场景拥有独立帧序列、逐帧时长、播放区间与循环模式（循环 / 单次 / 往返）；场景可新增、复制、左右排序、移除、双击重命名，操作后保持当前选择
- **绘制**：像素画笔 / 橡皮 / 填充 / 取色，洋葱皮，缩放与网格
- **精灵图导入**：按行列或单元格网格拆分帧，行优先恢复顺序并统一帧时长，导入为新场景
- **图集导出**：可选当前场景、全部场景或指定帧区间，生成透明背景 PNG 帧图集（1×/2×/4×/8×）
- **撤销重做**：绘制、帧操作、场景编辑、导入与旧版迁移全部进入撤销历史（⌘/Ctrl+Z，⇧⌘/Ctrl+Z 重做）
- **本地保存**：自动保存至浏览器本地存储，刷新后结构、选择与播放设置完整恢复；旧版单帧序列项目首次打开自动迁移（可撤销），损坏存档自动修复或重置
